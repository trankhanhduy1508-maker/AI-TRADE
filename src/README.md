# src/

Thư mục này **cố ý để trống** ở giai đoạn hiện tại.

Theo `PROJECT_CONTEXT.md`: dự án đang ở giai đoạn xây dựng nền tảng tài liệu,
giả thuyết và quy tắc — **chưa viết code**, chưa kết nối dữ liệu/tài khoản thật,
chưa có bot đặt lệnh, chưa huấn luyện model.

Khi bắt đầu có code thật (backtest engine, rule engine kỹ thuật...), cấu trúc
thư mục con cụ thể sẽ được thiết kế và ghi lại trong `CURRENT_STATUS.md` trước
khi triển khai.
